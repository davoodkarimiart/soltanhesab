# سلطان حساب | مخزن نقشه راه و مستندات

این مخزن (`davoodkarimiart/soltanhesab`) **مخزن برنامه‌ریزی و سابقه پروژه** است، نه سورس اجرایی قابل نصب. سورس اصلی در [hesabsvo](https://github.com/davoodkarimiart/hesabsvo) نگهداری می‌شود.

## وضعیت پروژه در ۲۴ اکتبر ۲۰۲۶

- **هاست تست:** نسخه `0.6.53` با MCP و OAuth فعال؛ اتصال دیتابیس، گزارش‌خوانی، عیب‌یابی لاگ‌ها و ایجاد بکاپ واقعی آزموده شده‌اند.
- **فاز ۱۰:** پذیرفته‌شده در دامنه عملیات Developer، با آزمون جامع بازیابی/زمان‌بندی در فاز ۱۲.
- **فاز ۱۱:** پذیرفته‌شده **در دامنه محدود مورد توافق کارفرما**: دیدن و تحلیل گزارش‌ها، بررسی خطاهای سایت و تهیه بکاپ. ساخت و نهایی‌سازی مالی با MCP و تست A/B مستقل جزو معیار پایان این فاز نیست.
- **تلگرام:** رویداد ارسال موفق قدیمی در لاگ وجود دارد، ولی ارسال آخرین بکاپ جدید به تلگرام هنوز تأیید نشده است؛ باید در فاز ۱۲ تست شود.
- **فاز ۱۲ (نهایی):** شروع مرحله سخت‌سازی، رگرسیون حسابداری، بازیابی بکاپ، تست نصب/ارتقا، بررسی مجوزها، همگام‌سازی GitHub و آماده‌سازی نسخه پایدار.
- **GitHub سورس اجرایی:** همگام‌سازی سورس پاک‌سازی‌شده `0.6.53` با `hesabsvo` هنوز باید توسط Work و با تأیید تست‌ها انجام شود. به‌روزرسانی این مخزن مستندات به‌معنی انتشار سورس در مخزن اجرایی نیست.
